# DepartureTrain

# 🚂 retro 3D train departure board

built this purely out of html, css, and vanilla js because i was obsessed with that heavy, tactile retro aesthetic. no webgl or three.js here—just pure css 3d transforms and a lot of math to make the box not float in the air. 

**[check out the live demo](https://departuretrain.vercel.app)**

## ✨ the vibe 
* **raw css 3d:** built an actual 6-sided geometric box using `preserve-3d` so it sits at a permanent, heavy angle. 
* **mechanical flip effects:** wrote a custom js scramble engine so the text cascades and locks in like actual vintage hardware. 
* **phosphor leds:** layered a micro-grid over the screen with deep amber `text-shadow` bloom to fake physical diodes.
* **tactile atmosphere:** slapped on a custom svg noise grain and radial vignette because flat colors are boring.

## 🛠️ stack
* html
* css
* vanilla js 
*(zero frameworks, zero dependencies)*

## 🚀 how to run
literally just clone the repo and double-click `index.html`. no `npm install` trauma required.
